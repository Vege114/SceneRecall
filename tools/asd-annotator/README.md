# 独立人工 ASD 标注小程序

这个小程序用于核对影片中“哪条人物轨迹正在说话”，独立于 SceneRecall 主界面运行。它只读正式素材库中的影片、角色资料和已有参考图；标注与短片副本保存到独立目录，不修改原片、主应用资产或声纹库，也不会开始训练。

## 启动

在 Windows 双击本目录的 `启动辉夜姬标注.cmd`。启动器使用本机已有的 WSL Ubuntu 和 SceneRecall 环境，随后打开浏览器；无需先启动 SceneRecall 主应用。界面地址为 `http://127.0.0.1:8766/`，请使用启动器自动打开的带本机访问凭证的页面。

当前启动器固定选择正式资料库 `D:\SceneRecallLibrary` 中的《超时空辉夜姬》，独立数据保存于：

```text
D:\SceneRecall\training\lrasd\manual-kaguya\
  clips\
    <片段ID>\
      clip.json
      frames.rgb
      audio.wav
      preview.mp4
      revisions\
```

`clip.json` 保存人工编辑、审核状态、修订号和来源审计；其余文件是该时间范围的本机副本。请备份 `clips` 整个目录。`server.private.json` 和 `server.private.log` 含本机访问凭证，不要随标注分享。

WSL 中也可从项目根目录启动：

```bash
bash tools/asd-annotator/start.sh
```

启动失败时查看独立数据目录中的 `server-errors.log`。不要将端口暴露到外网。

## 标注一段

1. 从页面顶部的“推荐标注任务”挑场景。队列按预先选定的分散场景排列，并显示训练、验证或测试用途；用途来自场景计划，不由人工说话标签决定。“保存并下一任务”先保存，再跳到下一个推荐场景，不会连续扩展原片。原有练习片段保留在“所有片段”中。

   当前已准备 24 个片段，每段 2–6 秒，总计 80 秒；按检测框完整度从基础到进阶排序。选片时废弃的未标注长候选只作缓存收起，任何已有人工修改仍保留可见。保存或切换时显示“正在处理，请稍候…”，完成后按钮恢复。
2. 点击一条人物名称，结合画面、声音确认人物。在该行角色下拉框选一次身份即可应用到整条轨迹；身份可以保留未知。角色参考图在折叠区中，供需要时辨认。
3. 选择帧范围，再用 S / N / U 标说话、未说话或不确定。只有一套帧范围，包含起点、不包含终点；例如 `[0, 50)` 是前两秒。新打开的片段默认选择整段。播放、拖动定位、点击色条及前后逐帧都保留已经选好的范围；需要单帧时点击“仅当前帧”。
4. 看清“本次处理”的人物和帧范围后操作。默认修改当前查看的人物；勾选多人或“全选人物”后会切到“勾选的所有人物”。S / N / U 按当前显示的目标生效。“只填不确定帧”默认关闭，因此可覆盖错误标签；打开后会保留已有标签，并在结果中报告保留数量。
5. 斜纹色条表示缺少人物框，与普通灰色“不确定”不同。缺框帧不能写说话或未说话标签；其余有框帧会正常标记。主按钮旁会列出跳过的缺框区间，例如 `[0, 13)`、`[32, 37)`，可点击“定位第一个缺框帧”检查，或“定位并画框”手动修正。人物未入镜时保持缺框，确实在画面中才补框。短轨迹也可能来自镜头切换，不应把新镜头自动当成原人物。
6. 检查当前人物的框、身份及说话标签，完成后勾选复核并保存。修改框、标签或身份会撤回复核，需要检查后重新勾选。拿不准、人物遮挡或无法判断声源时保留“不确定”，不要把所有未知帧当成未说话。

画框、复制框、轨迹备注和排除坏轨迹放在“修正人物框 / 备注 / 排除”折叠区。“将当前框应用到选中帧范围”逐帧复制同一框，不会推算运动或自动插值，仅适用于确认位置不变的范围，复制后仍需检查。

需要自选时间时展开“自选时间片段”，输入原片秒数，允许 0.64–8 秒并按 40ms 对齐。准备只解码音画、提供待核对框，不生成说话或身份答案；新片段标签均为不确定。若要导出两秒窗口，建议 2、4、6 或 8 秒。浏览器未保存修改不会进入导出；切换任务有草稿保护。版本冲突时保留本地草稿并核对服务器，避免覆盖。

| 操作 | 快捷键 |
| --- | --- |
| 播放 / 暂停 | `Space` |
| 前后逐帧，40ms | `←` / `→` |
| 选中范围标为说话 | `S` |
| 选中范围标为未说话 | `N` |
| 选中范围标为不确定 | `U` |

在输入框中编辑时不会触发快捷键。界面支持循环播放、0.5 倍速和撤销上一步未保存修改。

## 批量操作

同一人物的身份按整轨保存，例如辉夜、彩叶两人分别给两行选一次角色即可。勾选要一起处理的人物，或点击“全选人物”，再设定唯一的帧范围，使用主操作区的 S / N / U。点击人物名称只切换查看人物；上方“本次处理”始终显示实际操作目标。

两人轮流说话时，先勾选两个人，再点击正在说话的人物名称，用“仅当前人物说话，其余勾选人物未说话”，一次处理两人的该范围。仅适用于你确认范围内发言人不变时；出场不等于正在说话。每次结果在主按钮旁显示修改、缺框跳过、保留已有标签的数量。批量操作不会补框或猜标签，整批可一次撤销，再保存。

“更多人物选择”提供反选、选当前帧人物、未复核或同角色轨迹。“高级：本段批量身份、复核与排除”提供整轨身份、批量复核、排除和恢复，标签操作与主区使用相同帧范围和“只填不确定帧”选项。两个人身份不同，请分别指定，不能统一设成同一个角色。

页面底部还支持勾选多个已就绪片段，使用“跨片段批量操作”。可按已关联角色、未知身份、未排除或全部轨迹筛选，批量改标签、身份、复核、排除状态，并直接保存。执行前先保存当前草稿；预览会显示命中片段与轨迹数。不同片段的“人物1”不会自动认作同一角色。每次保存校验修订号，发生冲突或失败时停止后续保存，界面报告已完成数量；“撤销上次跨片段批量操作”可恢复已完成部分（保留修订历史）。跨片段撤销记录在当前页面内保留，刷新后仍可检查磁盘的 revisions 历史。

## 导出

页面的“导出已保存标注 JSON”用于查看、备份和交换已保存的标注；它不包含完整训练音画资产。需要训练资产时，在已安装 NumPy 和 OpenCV 的独立视觉环境中执行：

```bash
cd /mnt/d/SceneRecall
.venv-visual/bin/python scripts/export_lrasd_annotations.py \
  --annotations-root training/lrasd/manual-kaguya/clips \
  --output training/lrasd/manual-kaguya-export-v1
```

`--annotations-root` 必须指向 `clips` 目录，不能传页面下载的 JSON 文件。`--output` 必须是新的目录，已有导出不会被覆盖。后续修订请使用新的输出目录。

导出结果包含 `labeled.jsonl`、`label-summary.json` 和 `assets/`。导出器只接受已保存修订中明确复核、未排除的轨迹，保持人工输入的逐帧标签：`1` 说话、`0` 未说话、`-1` 不确定。每个不重叠的 50 帧窗口对应 2 秒、25fps 全身灰度 112×112 图像和严格对齐的单声道 16kHz PCM16 音频。未知且无框的帧使用零图像并遮罩；不会补标签、插框或拼接尾帧。少于 50 帧的余数会舍弃并记录。

请检查控制台的接收、拒绝和舍弃数量，并阅读 `label-summary.json` 的 `rejected_tracks`、`skipped`、`discarded_tails`。未复核、全未知、坏框等情况都有原因；缺失目录、坏 JSON、音画长度错误、媒体哈希不匹配会明确失败。导出中若修改了原标注，需换一个新目录重新导出。

每条样本记录 `human_annotated=true`、`human_frame_asd_ground_truth=true`、`label_source=human_frame_asd`、`machine_generated=false`，并保留原片 SHA256、片段时间、音轨、修订号、标注哈希和人物框审核来源。检测器提供的初始框仍保留其来源，不会被改称人工绘制；勾选复核表示你已检查它。角色 ID 只是人工关联字段，不会自动写入可信身份或声纹库。

## 后续训练的边界

未传场景计划时，兼容导出保留同一作品分组且全部为 `split=train`。使用本轮固定计划时，同场景全部人物和窗口共用一个分组，按预先确定的训练、验证、测试划分导出，并检查时间隔离；不会随机拆分相邻帧。这批数据衡量同一影片的场景留出效果，跨作品验证仍需独立动画素材。

人工监督 `human_frame_asd` 与官方训练回放模式现已接入。请按 [人工标注、微调与评估](HUMAN_TRAINING.md) 使用固定场景计划，先检查复核完成度，再导出、评估基线、微调及比较。无计划的旧导出仍全部为 train，不能直接作为有独立验证测试的完整训练轮次。未满足复核、类别覆盖及最少窗口要求时，流程报告阻塞项；标注不会自动开始训练。
