# 整理已有资料库的人物裁剪与身份快照

已归档的单集可能同时保存了原帧和从原帧裁出的普通人物 PNG。离线工具可以核对这两份数据，在逐字节重建成功后取出冗余的普通 PNG。应用预览仍从资料库的原帧和人物框生成同一张图，不需要原视频、联网或重新运行模型。

## 先查看可整理范围

在项目根目录运行：

```powershell
.\.venv-windows\Scripts\python.exe scripts\compact_person_crops.py --library D:\SceneRecallLibrary
```

默认按资产列出普通 PNG 的数量和逻辑字节上限。添加 `--asset 资产ID` 可只看一集，也可重复指定多个资产。添加 `--verify` 会实际重建、比对并列出无法验证的条目，资料库保持只读。估算和核验均可在服务开启时运行，显示扫描期间的状态。

## 处理已经核对的范围

停止正在使用该库的 SceneRecall 服务和其他写入任务，再运行：

```powershell
.\.venv-windows\Scripts\python.exe scripts\compact_person_crops.py --library D:\SceneRecallLibrary --asset 资产ID --apply
```

执行时会重新核验每个候选，不依赖前一次扫描结果。工具读取普通裁剪、同一区域的持久记录、历史记录、已有任务回执、原帧注册表和库内原帧，按应用预览的实际算法生成 PNG。发现来源缺失、历史重建结果冲突、字节不同、文件被登记为独立证据帧或属于文件系统链接时，裁剪继续保留。属于旧场景请求或其输入历史中直接引用的 PNG 也继续保留，供恢复任务时按原文件名读取。仅对通过核验的条目原子写入区域校验信息，然后移除冗余文件。中断后可使用同一命令继续。输出中 `removed_bytes` 为已移除 PNG 的文件长度之和，区域记录新增的校验字段和文件系统分配粒度会影响真实净节省。

新版应用与整理程序对同一库互斥，旧版服务需先停止。工具直接读取已存在的清单，不初始化或修复正式库。原视频、原帧、人工决定、独立参考照片与特征向量维持现有用途。后续任务是否继续生成普通 PNG 由资产的视觉身份配置决定；选择 `discard` 可控制新任务的留存。[普通裁剪配置](PNG_RETENTION.md)

## 整理大型人物识别 JSON

新写入的视觉身份快照 `identity/visual/latest.json` 和检索任务回执 `analyses/*/retrieval-local-identity.json` 使用紧凑的标准 JSON。现有文件可用同一工具单独处理。这个选项仅选中上述两类文件。

```powershell
.\.venv-windows\Scripts\python.exe scripts\compact_person_crops.py --library D:\SceneRecallLibrary --identity-json-only --verify
```

省略 `--verify` 可统计文件数和原始字节数。核验显示可节省的逻辑字节，停止该库的写入任务后，将 `--verify` 改为 `--apply` 即可整理。工具在每个文件中仅去除 JSON 行首行尾的空白和换行，逐项比较解析结果后原子替换，保留数字拼写、字符串内部空白、区域、模型结果和回执签名。重复执行会跳过已经整理的文件。

## 2026-11-11 本机核验

《梦限大》4 集的 4 份视觉身份快照、4 份检索身份回执在独立副本上实测。8 个 JSON 从 411,423,120 字节降至 267,709,612 字节，节省 143,713,508 字节（137.06 MiB，占这 8 个文件的 34.93%）。每个文件与来源副本的解析结果逐项相等，第二次执行节省 0 字节。核验及执行各一次分别耗时 9.442 秒和 9.608 秒。此项节省不含普通 PNG 或原始 JPEG。

正式库 16 个资产合计 29,931,730,168 字节（27.88 GiB，按文件长度，库外原视频未计入）。帧目录共 15.71 GiB；身份资料含 10.44 GiB，其中 9.44 GiB 来自 27,637 张普通人物 PNG，均在《少女歌剧》12 集。《梦限大》4 集已无普通人物 PNG，该部分可整理量为零。这 4 集仍保存约 5.27 GiB 的原始 JPEG 证据帧。全库按集核对同字节 JPEG，107,740 张中只发现 234 份额外副本，合计 3,146,363 字节。

正式库用于只读统计和抽样。按每集裁剪文件名排序，从首、中间等距位置和尾部取 6 张，复制 72 张及对应原帧、区域、相关历史与回执到隔离库；没有复制原片。隔离执行移除 72 张，共 23,989,216 字节。所选资产文件总量从 37,830,399 降至 13,856,447 字节，净减 23,973,952 字节。应用逐张预览后，72 份 PNG 内容哈希与整理前完全一致；相同范围再次执行移除 0 个。全库 9.44 GiB 是候选文件量，最终可移除字节要以全量逐项核验为准。
