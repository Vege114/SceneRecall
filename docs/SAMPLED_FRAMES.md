# 采样画面的展示与存储

搜索结果进入可视范围时，浏览器自动请求画面。视觉命中使用具体的原帧 ID；只有文本或声音线索的结果按播放位置显示原片预览，方便直接核对。单集的字幕列表也会在台词旁显示对应画面。视觉记录缺少登记证据图时，页面标明「原片时间点预览」。展开完整证据条仍可查看其他帧。

## 保留的数据

- 对已登记的精确采样，库保存原片 SHA-256、源 PTS、时间基和原 JPEG 摘要。读取时核对原片身份，解码到指定帧并比对图像摘要。均匀采样和 OCR 还需核对请求时间、实际呈现时间及裁剪信息。普通画面从临时文件提供，近期使用的采样图共用有容量上限的缓存。浏览结果不会把临时图片重新写回每集的 `frames/`。
- 已有视觉索引和文本资料继续用于召回。少量活动任务在编码、存储回执或准备恢复期间可以有工作用 JPEG。成功收尾时释放可复现的普通采样图。受旧冻结请求直接引用、无法验证的图以及独立证据按各自用途保留。
- 人工确认、可信参考和收藏使用独立图片。普通台词收藏会尝试保存该时间点的预览；原片已离线且无预览时仍可保存文字。作品的原片可以重新定位，内容验证通过后可继续显示普通采样画面。仅有时间戳或向量无法从缺失的原片还原画面。

## 准备移走原片时

在设置页创建备份时勾选包含采样画面的选项，会把已释放的采样帧分批还原到 ZIP。可以单独勾选这个选项，也可以同时打包原视频。恢复含采样画面的备份后，已归档的采样帧可以在原片离线时显示。对单独保留的台词或声音时间点预览以外的任意新时间点，仍需原片。默认的元数据备份只保存已有的资料与定位信息。

## 整理已有资料库

在仓库根目录先运行只读盘点。Windows 示例使用项目 Python 环境。

```powershell
.\.venv-windows\Scripts\python.exe scripts\compact_sample_frames.py --library D:\SceneRecallLibrary
```

添加 `--verify` 可对照实际原片逐批解码。停止使用该库的服务和其他写入任务后，使用 `--apply` 写入重建信息并删除逐字节相同的普通 JPEG。可重复传入 `--asset <资产ID>` 限定范围。每批先提交配方、再核对并移除原文件，中断后可用同一命令继续。已独立保存的参考图、非采样图片及原视频均可继续使用。

## 浏览器验证

在《BanG Dream Yumemita》第 2 集独立副本中保留 6,297 个登记帧及其重建信息，采样目录中的 JPEG 数为零。Chrome 查询「舞台上的乐队演奏」返回 122 条结果。首条和滚动后的第九条都自动显示了 640 × 360 的时间预览，视觉命中和单集详情显示了原始分辨率的证据帧。对抽查的已登记画面逐张比对 HTTP 响应与归档中的 JPEG SHA-256。结束时采样目录的 JPEG 数仍为零。

在同一浏览器流程中另选中 159.493 秒的视觉命中并收藏。清空测试副本的片源映射后，收藏页仍然自动显示选中画面，HTTP 返回的 328,251 字节与已登记 JPEG 摘要相同。一次收藏新增 1 份独立原帧，点击定位仍为 159.493 秒。

直接打开同集 1.100 秒的字幕链接时，台词旁自动加载了 640 × 360 的原片预览，采样目录仍为零。另用真实合成视频验证新任务成功收尾、重试复用既有索引和模型回执、原片丢失时的保留处理，以及自包含 ZIP 在独立资料库恢复后逐张返回原有 JPEG 字节。

## 项目中的历史测试输出

对既有研究与测试目录另行清理了 54,731 个可确认为应用采样的 JPEG 路径。其中 51,840 个来自已登记的实验库，另有 2,891 张通过测试的抽帧规则、原有校验值或合成图像字节进行确认。文件长度合计 1,244,608,381 字节，部分旧副本使用硬链接，不能将这一数字直接换算为磁盘可用空间的增长。189 份独立人工证据或别名图像另行留存。原视频、训练数据、软件依赖、截图和 24 张人工导出的历史对照图继续保留。两个故意模拟原片不可用的历史实验，重放普通采样画面时需恢复同源视频。
