# SceneRecall 0.3.0

0.3按「项目（系列）→ 动画／季度 → 单集」整理资料，支持全局、项目、动画及单集检索。TV与剧场版可以收纳在同一系列，各自保留初始档案和剧情连续上下文。旧发行档案可在显示层补齐动画类型、名称与集号，回收恢复保留证据。

相同视频可反复导入，每次新条目建立独立档案，资料库与回收站均不阻止新导入。请求重放与同条目重试仍幂等，原视频保留原位。macOS选择窗口直接使用AppKit，支持多选并移除对Finder自动化的等待。人物和剧情证据读取复用请求内快照，避免大目录反复解析；读接口在线程池中执行，保持页面与文件窗口响应。

此版本也合入开发分支此前完成的字幕引导场景分块与深入理解、连续剧情记忆、Bangumi人物档案与语种姓名、原始ASS／容器字幕提取、批量导入与分析、任务内模型选择、集中并发设置和阶段断点恢复。

2026-10-15 更新：多集关键帧扫描与台词前置使用独立有界并行池，先整理同批台词再按集理解；开始分析、片段深入及角色重识别均可跳过用量估算。用量界面新增考虑并发与共享连接的处理耗时范围，队列用季集号／文件名区分同名视频。初步场景即可关联有证据的角色档案，演职员文字与剧情分离；单集详情可直接从 Bangumi 读取职位和参与集数。新任务冻结新版提示词，旧任务保持原版本与成功回执。

本轮验证：后端 **1,080 项通过**（3 项原生实窗默认跳过）、前端 **198 项通过**；TypeScript、生产构建、Ruff 和 diff 检查通过。12 份合成视频完成真实扫描，公开 Bangumi 演职员取得 288 条职位关系并通过 12 集投影检查；未运行付费模型或真实整剧识别。详见[验证记录](VALIDATION.md)。

此前验证：后端1,034项、前端187项通过；3项macOS原生实窗另行通过；TypeScript、生产构建和Ruff通过。12集真实原素材隔离回归通过，源文件不变，未调用模型；旧库副本恢复后12集归为同一动画。详细证据及平台边界见[验证记录](VALIDATION.md)。
