# SceneRecall 0.3.0

0.3按「项目（系列）→ 动画／季度 → 单集」整理资料，支持全局、项目、动画及单集检索。TV与剧场版可以收纳在同一系列，各自保留初始档案和剧情连续上下文。旧发行档案可在显示层补齐动画类型、名称与集号，回收恢复保留证据。

相同视频可反复导入，每次新条目建立独立档案，资料库与回收站均不阻止新导入。请求重放与同条目重试仍幂等，原视频保留原位。macOS选择窗口直接使用AppKit，支持多选并移除对Finder自动化的等待。

此版本也合入开发分支此前完成的字幕引导场景分块与深入理解、连续剧情记忆、Bangumi人物档案与语种姓名、原始ASS／容器字幕提取、批量导入与分析、任务内模型选择、集中并发设置和阶段断点恢复。

验证：后端1,019项、前端187项通过；3项macOS原生实窗另行通过；TypeScript、生产构建和Ruff通过。12集真实原素材隔离回归通过，源文件不变，未调用模型；旧库副本恢复后12集归为同一动画。详细证据及平台边界见[验证记录](VALIDATION.md)。
