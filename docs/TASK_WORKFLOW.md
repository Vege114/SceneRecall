# 任务配置与进度

单集和批量分析都先集中设置，再点击「开始任务」。关键帧划分、角色确认和后续分析会出现在同一个任务中；无需在提交前另做扫描或角色选择题。

## 开始任务

从视频详情或批量选择进入分析窗口。窗口自动载入已保存的默认值，可按本次需要调整：

| 设置 | 用途 |
| --- | --- |
| 处理策略 | 「场景理解」整理台词、划分场景并深入理解复杂片段；「画面检索 · 可选 VLM」建立画面、已有字幕和人物检索资料 |
| 画面理解／画面字幕 OCR | 场景理解中选择需要的阶段。OCR 仅适用于烧录字幕；容器或外挂文字字幕在本地使用 |
| 使用 VLM 生成局部描述与事件 | 画面检索的可选生成阶段；关闭时不调用生成式 VLM，已启用的本地人物匹配仍执行 |
| 各阶段连接、模型 | 分别选择台词整理与视觉分块、深入理解／局部记录、字幕 OCR 的连接；Codex 可另选模型与思考等级 |
| 执行方式与并发 | 设置适用阶段的串行／并行和任务并发上限；实际请求同时受连接上限与预算约束 |
| 字幕参数与预算 | 调整 OCR 采样和区域，以及每个视频的请求数、可用时的费用上限 |

当前只有一种实现的本地步骤显示为锁定选项：关键帧方法、人工角色确认、本地检测／CCIP、文字字幕处理，以及检索时的当前图文编码器。这些选项展示任务如何处理，保留将来扩展的位置；人物识别继续使用作品／资产的既有配置。

默认分析全片，批量任务各自使用本集时长。可以填写开始／结束时间，或点击「先试运行前 60 秒」。分析范围和「忽略已有分析缓存，重新处理」只作用于本次。

开始／结束时间指定原片中的时间位置，与任务实际运行耗时是两回事。任务可以运行超过原片时长；「整片 complete 总墙钟不超过原片时长」是开发性能验收目标，不是用户启动、继续或完成任务的约束。请求数和费用预算、暂停／取消，以及单次请求或步骤的故障超时仍按各自规则生效。

选择 Codex 的阶段会由应用调用本机 CLI，使用已登录账号。选择 API 阶段则使用对应连接中的模型；没有启用生成阶段的本地画面检索不需要 Codex。任务卡保留实际使用的连接类型、模型与思考等级，恢复不会切换成后来保存的默认模型。

## 保存默认值

在「模型与设置 → 默认任务配置」编辑与启动窗口相同的处理选项，点击「保存默认值」。也可在启动窗口勾选「设为默认值」，随这次提交保存。

保存内容包括策略、阶段、VLM、各阶段连接与模型、执行方式、字幕参数和预算。新任务使用新默认值，已提交任务保持其创建时的选择。连接本身及 API 凭据在「模型连接」管理，连接并发上限在「执行与并发」管理。

应用初始使用场景理解；画面检索的 VLM 初始关闭。保存自己的默认值后，下次会恢复你的选择。默认值保存成功但提交失败时，会明确提示这两个结果，修正后可重试提交。

## 在队列中完成角色确认

点击「开始任务」后即可在任务队列查看三个阶段：关键帧划分、角色确认、分析处理。关键帧会自动划分或复用有效结果；需要角色判断时，任务进入「等待确认」，不会占着分析工作线程等待。

普通统一画面分析先完成本机关键帧，再检查角色确认条件；台词整理预取和后续模型分析也须通过这个门槛。没有待确认角色时会自动继续，因此门槛不表示所有任务都会停下来等待人工。

1. 点击任务的「确认角色并继续」，直接在带图角色卡中选择本作品需要识别的人物。可搜索姓名／别名，逐个勾选或全选／取消当前显示的角色，点击「保存名单并生成候选」。同一作品各集共用名单，已保存的人工确认及否定保留。空名单保存后跳过生成，可以直接继续。
2. 名单保存成功后，先分批缓存所选角色参考图，再跨集执行本地人物检测与 CCIP。界面每轮最多 24 集、作品总计 120 帧、每集 12 帧；优先复用已登记帧。可查看逐集进度或「停止补充候选」，关闭窗口后可回来继续。中断恢复及每轮预算见[角色确认说明](CHARACTER_CONFIRMATION_QUEUE.md)。
3. 同一人物区域仅进入一个角色候选列表或待判定池。无校准或身份不确定时，须在待判定池明确选角，再核对原片并提交，不能把排名当作确认。每个角色最多展示 3 张去重候选，待判定池分页；更多采样仍不能保证所有角色都有正确候选。缺参考、检测无效及预算用完分别显示，没有候选不代表未出场。
4. 所选角色都已确认或明确跳过，且采样（包括停止收尾）与保存结束、未提交勾选及未知请求结果处理后，点击「继续任务」。只放行当前批次中同作品的等待任务，各项再检查自己的范围；用户暂停的任务保持暂停。其他作品及其他批次仍须各自核对并明确继续。暂时跳过是作品范围的核对暂缓，可恢复，不表示角色缺席或身份被否定。

没有待核对角色时自动继续。等待任务可以暂停、取消；重启后状态仍保留。角色确认的详细操作与证据规则见 [视觉身份说明](VISUAL_IDENTITY.md)。

继续后任务先回到队列，排队不表示后续模型分析已完成。2026-11-11 在隔离库的两集完整原片中，用户确认 6 个角色后，按其指令暂缓其余 13 个待确认角色；真实界面一次继续即让同批两集重新排队，已确认身份与参考保持不变。该次验收关闭分析 worker，只验证放行，不代表两集分析或全部 13 集流程完成，详见 [验证记录](VALIDATION.md)。

候选准备使用上述独立的本地帧预算，不改变关键帧算法、分析任务的模型请求预算或成功结果复用规则，也不自动启用作品的视觉识别设置。历史任务以及片段深入理解、旧角色重识别等专用入口保留原有流程。画面检索的开发验收目标与进展见 [检索策略说明](RETRIEVAL_FIRST.md)，本次界面调整不代表模型准确率或处理性能通过新的验收。
