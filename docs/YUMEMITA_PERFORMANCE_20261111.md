# YumeMita 四集的搜索、播放与资料库空间

本文记录 2026-11-11 搜索与播放第一轮优化，在 Windows 本机将 `9a7fce6` 与 `6c41d5e` 对照。该轮使用《BanG Dream Yumemita》第 1–4 集的独立档案副本和现存原片，正式库只读。下文磁盘数字为随后清理采样 JPEG 之前的盘点。后续的实际整理和无采样图浏览器验证见[采样画面存储](SAMPLED_FRAMES.md)。

## 搜索到首屏

在 Chrome 155 生产前端实际点击检索，查询「舞台上的乐队演奏」。使用页面默认混合检索、严格高于 50% 的阈值、本地视觉编码器和 1 GiB 矩阵预算。未配置远程模型，未开启增强或视觉核对。两个版本从同一 SQLite 备份开始，分别启动进程，等待索引、统计和本地编码器预检就绪。每个版本先查第一集三次，再查四集三次。每次用新页面，浏览器上下文与服务进程在同一版本内复用。测试没有清除操作系统文件缓存。

浏览器在动画帧回调中记录列表出现，以及第一条结果图片成功加载、具有实际宽度且已进入视口的时刻。它们是用户可见状态的采样，含浏览器调度。应用内的「搜索总耗时与阶段记录」另外记录 React 提交和服务端分段。每种条件只有少量轮次，进程首次请求还包含模型启动、矩阵构建及可能的重试。机器上同期有开发验证活动，表中秒数适合作为本机样本。

第一集召回集合有 846 个候选，四集有 2,001 个。两种范围最终都返回 122 条，两个范围的结果不同。每个范围内，改动前后三轮的完整有序结果数组分别具有相同 SHA-256，覆盖排序、分数、当前证据、缩略图与播放定位字段。第一集权威来源恢复的返回记录从 1,856 条降至 113 条，四集从 6,611 条降至 115 条。来源记录与展示结果的计数口径不同，展示还包含组合结果。第一集暖查询记录的文本读取次数从 7,473 降至 750。

优化将候选、合并成员和来源 ID 定位到所属素材，按需读取活动窗口、身份附属记录、影响观察的场景和时间相连的字幕。查询保留原有的三轮版本核验。知识词法匹配复用本轮已经生成的作品资料，整理资料时提前跳过还未审核通过的卡片。

## 单集播放器

从第一集的首条结果进入，实测目标为 **278.800 秒**。计时从触发结果链接开始，到播放器元素出现以及浏览器已完成定位且可以继续播放。改动前分别为 **3.63 秒、6.25 秒**，改动后分别为 **0.044 秒、1.64 秒**。两边都定位至同一时间，浏览器最终就绪状态为 4。另两次从资料库页面进入同一定位，改前可播放时间为 28.50、13.97 秒，改后为 1.62、1.77 秒。

浏览器可以先使用列表中的资产资料创建播放器；直接打开链接时可单独请求播放元数据。画面页按当前素材请求视觉证据及其依赖，字幕页读取时间线，运行记录页另取参数正文。当前画面页仍取回该集的全部画面资料。播放时复用按资料与筛选词计算的排序、注释索引和时间边界。

另从同一位置实际连续播放 30 秒，每版各一轮。两次均播放 720 帧、零掉帧，均触发 113 次播放时间更新。浏览器记录的脚本执行累计时间从 0.699 秒降至 0.338 秒，主线程任务累计时间从 1.875 秒降至 1.632 秒。这是同一片段的单次对照。

## 第四集正在扫描时

另起两个测试进程，从同一索引备份启动。在服务的后台线程循环执行真实 PyAV 关键帧扫描，输入为第四集前 120 秒，同时在浏览器查询第一集。负载覆盖本地解码与扫描阶段，没有创建付费模型请求或整集队列任务。

第一集第二次搜索的列表耗时从 **40.75 秒降至 2.92 秒**，第一张缩略图从 **41.06 秒降至 3.03 秒**。有后台扫描的 4 次搜索均返回与同范围空闲测试完全相同的结果。

直接点击搜索结果时，播放器从 **7.63 秒降至 0.053 秒**出现，同一次操作中定位后可播放却从 **11.07 秒增至 26.77 秒**。另两次从资料库跳到同一位置，改前可播放耗时 31.30、30.86 秒，改后为 1.61、1.84 秒。全部定位到 278.800 秒。该组仅各 3 次，且入口不同。记录覆盖播放器出现与媒体可播放两端，中间的磁盘读取、浏览器取流、解码及缓冲时间尚未分别测定。

## 磁盘占用

YumeMita 四集原始 JPEG 证据约 **5.27 GiB**，普通人物裁剪 PNG 为 **0**。四集的 8 份人物快照和任务回执，在独立副本上无损整理后从 411,423,120 字节降至 267,709,612 字节，实际节省 **137.06 MiB**。逐文件比较了解析结果，第二次执行节省 0 字节。新写入的同类档案自动使用紧凑 JSON。

正式资料库中仍有其他作品的派生档案。约 **9.44 GiB** 的普通人物裁剪可逐张核查；该数字是候选文件总量。72 张隔离样本全部成功重建并通过字节比对，扣除新增校验信息后净省 23,973,952 字节。全库按集核算，相同 JPEG 文件的额外副本合计约 3.15 MB，单纯去重对原帧占用帮助很小。使用命令及旧任务的保留条件见[资料库空间整理](ARCHIVE_STORAGE.md)。

逐轮搜索、播放读数与结果摘要见[浏览器测量数据](benchmarks/yumemita-performance-20261111.json)。记录不含原视频、缩略图或媒体路径。改动前首轮基准在数据写完后等待浏览器连接关闭，已结束该隔离进程；后续测试为服务退出设置了超时。连接关闭时的取消日志发生在测量结束后。
