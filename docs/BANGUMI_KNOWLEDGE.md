# 从已保存 Bangumi 档案准备知识资料

此功能在[作品知识资料库](LIGHTRAG.md)基础上，复用本机已保存的作品和角色档案。导入关联 Bangumi 的动画时会自动准备资料；已有影片可在作品设定库或知识面板点击整理按钮。

- 保存作品简介、角色简介及资料字段的来源正文、原始条目 URL、获取时间和内容哈希。角色说明关联现有内部角色 ID，初始资料卡为待核对候选。
- 重复整理保持幂等，保留已核对、拒绝或撤销决定；来源变化生成新快照并使旧导入来源失效，新卡重新待核对。
- 各集按明确作品版本复用作用域；身份不唯一时先保存来源，补齐角色身份后可重新整理。不以同名作品自动合并，也不把声优、制作人员或主配角关系当作剧情关系。
- 该步骤只读本地档案，不联网、调用模型、自动建库或确认影片出场。资料卡核对和 LightRAG 建库仍需显式操作。
- 整理失败会在导入任务显示可恢复回执，不阻止影片导入。没有保存档案或缺少字段时给出说明，可继续手动补充。

API：`POST /api/assets/{asset_id}/knowledge/bangumi`；已有明确作用域可用 `POST /api/work-entity-scopes/{scope}/knowledge/bangumi`，请求体为 `{"asset_id":"..."}`。均使用本机会话认证，服务端读取自有档案，不能提交远程 URL 或任意档案正文。

验证覆盖见 `tests/test_bangumi_knowledge.py`、`tests/test_bangumi_knowledge_workflow.py`、Bangumi 导入工作流回归及前端知识面板/导入回执测试。文档所述已有本机档案数量属于此前隔离验证，不是本次重新运行网络或模型实验。
