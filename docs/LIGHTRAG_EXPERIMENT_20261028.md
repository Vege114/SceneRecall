- 每模式 3 轮冷条件、5 轮暖查询，每轮 21 问；暖轮另有 21 问预热。合计 336 次计量请求、42 次预热。冷条件每问关闭知识 worker、清空可丢弃 catalog/视觉矩阵缓存；持久关键词和图文查询缓存保留，OS 文件缓存未控制。基线首轮加载了视觉模型，后续轮次可使用既有文本查询向量，不能据进程树总 RSS 宣称 LightRAG 降低内存。

| 暖条件知识分支整体 | 223 毫秒 | 351 毫秒 |
| 暖条件知识映射和影片读取 | 56 毫秒 | 72 毫秒 |
| 暖条件 HTTP 当前资料复核 | 5.328 秒 | 5.499 秒 |

B 暖条件 LightRAG 调用整体约 52 毫秒，其中 SDK 检索约 22 毫秒；冷条件调用整体约 3.076 秒，包含进程启动和索引载入。不能把 SDK 检索耗时当成应用端到端延迟。当前整集权威资料读取是主要端到端瓶颈，运行顺序和文件缓存也会影响差异。

- 首次成功建库：12 卡/12 块，74.29 秒，25 次文本请求，65,067 tokens。
- 更新试验在独立副本新增一张有出处的华恋事实卡：12→13 卡，ready→stale→ready，全作品重建 84.11 秒，27 次文本请求，70,831 tokens。未重建影片索引。
- 全部查询（含预热）：29 次远程关键词请求、19,457 个可获得的远程 tokens、189 次本地 embedding 调用。暖查询中的 `トップスタァ` 仍每轮发生一次关键词调用，不能假设所有重复查询都零远程调用。
- DeepSeek `deepseek-v4-flash` 为请求模型名，官方目前将旧名称路由到较新的 Flash 模型；不能把请求别名视为永久固定权重。显式 `text_thinking=disabled` 被写入配置及索引签名。未配置单价，金额为未知；本地 embedding 不报告不存在的 API token。
- 默认高思考模式的早期构建已取消，已知 10 次请求、76,132 tokens，另有 1 次在途用量未知；该轮回执保留，未纳入成功建库或查询速度比较。
- 本地量化多语言 MiniLM：384 维、CPU，模型及 tokenizer 共 266,904,093 字节，固定 revision 与逐文件 SHA-256。知识查询 worker 进程树采样峰值 RSS 约 1,086,361,600 字节；更新试验约 1,145,090,048 字节，包含 Windows 监督进程，不是 GPU 显存数值。
- 主试验每作品来源快照 615 字节、共享 catalog 50,922 字节、派生目录约 1,373,663 字节；公共调用回执另约 172,559 字节。派生目录包含保留的失败代，模型、原片、既有影片向量及基准输出另计。
- 更新副本的新代为 950,686 字节，保留旧代后的派生目录增加 953,638 字节。文件存储仍将图和向量载入内存。

调用和取消均有持久回执。过程中还修复了无关裁剪/历史文件的全目录版本扫描；单次诊断由约 4.3 秒降为约 4 毫秒。修复前未完成的基准目录保留，正式配对从头重跑，此单次诊断不作为统计性能承诺。

## 一致性专项

三项独立安全试验通过：来源撤销使旧代 stale 且无撤销资料卡；绑定撤销后旧 SQL 的 confirmed 投影不能复活影片关联；合成同名作品只返回本作用域资料，并拒绝外部正式 ID。对应测试和真实副本结果保留，不冒充另一部真实动画的检索质量。
