# 搜索阈值与候选数量（2026-11-04）

本轮将检索界面的默认阈值设为 **50**。筛选规则是匹配分 **严格大于** 阈值，分数是相对排序分，不是人物置信度或正确率。

[交互曲线存档](search-threshold-curve-20261104.html)保留历史阈值 75 的初始位置；[完整可移植数据](search-threshold-distribution-20261104.json)保存全部 **3,669** 个窗口的 raw RRF、人物依据加权后的有效分、最终分、命中帧与分支排名，可重新绘图。

## 数据范围与结果

曲线表示 **按现存索引离线重算的候选窗口数，权威回源与合并前**。重算使用已有 SQLite 记录、图像向量及缓存查询向量，没有调用搜索 API、模型推理或修改生产库。它不是各阈值下最终 UI 返回数量。

| 严格大于阈值 | 离线候选窗口数 |
| ---: | ---: |
| 0 | 3,669 |
| 10 | 367 |
| 20 | 143 |
| 30 | 71 |
| 40 | 37 |
| **50** | **16** |
| 60 | 4 |
| 75 | 0 |

**50 对应 16 个索引候选，不是实测 UI 返回 16 条。** 原查询为“爱城华恋与神乐光站在东京塔上”，范围为该动画全 12 集、visual 类型。已知 E01 606–612 秒目标窗口 `rw_89a63b12092fc1bfae1bebff` 的最终分为 **24.9958**，因此默认 50 仍不包含它；仅把阈值降低到小于其精确分 `24.99578343734188`，才会在本次离线候选中包含它。

最终规则使用全体候选的 raw RRF 最大值作固定分母：`100 × 有效分 / 全体 raw 最大值`。本次分母为 `0.025978407557354925`，最高最终分为 **63.1041**。人物依据不足只降低相关的非视觉贡献，不扣除视觉票，也不把候选身份升级为确认。

## 核验与限制

- 重放得到 lexical 3,377、visual 3,669、目标人物 2，与保存记录一致；已保存的 21 条历史实验结果，其命中帧、raw/effective 分和身份状态逐条一致。这 21 条仅用于校验，没有冒充全量分布。
- semantic/concept 两分支沿用捕获时均为零的事实，没有重新执行；历史未保存全库 revision，故完整分布应称为“现存索引离线重算”，不能声称逐位还原历史全量响应。
- [最终规则的实际 API 记录](search-character-priority-final-20261104.json)在阈值 **75 返回 0 条**。这是已测事实；其余阈值曲线没有执行权威回源、合并去重或新 API 测量。
- 任意阈值 `t` 的精确离线数量：统计数据文件 `sorted_match_scores` 中 `score > t` 的个数；`curve_integer_thresholds` 提供 0–100 整数刻度，`candidate_scores` 保留全部逐窗口证据。

人物漏检与跨帧归属的原始核查见[窗口身份对照](window-identity-comparison.json)，不同文本提示的独立视觉实验见[视觉探针结果](visual-probe-results.json)。两者均不等同于本次最终排序分布。归档 JSON 已将本机绝对路径替换为逻辑路径，并标记 `sanitized`；不包含图像、模型缓存或认证值。
