### 复现真实素材检查

安装开发依赖后，在仓库根目录运行（目录和 glob 由本机素材决定）：

```sh
uv run python scripts/verify_container_subtitles.py --media-dir /path/to/media \
  --glob '*Tenmaku no Jaadugar*.mkv' --expected-episodes 12 \
  --output /tmp/subtitle-verification.json
```

脚本仅输出统计、文件名和时间边界，不输出或保存字幕正文/查询文本到报告。独立原始包文本对照目前支持 ASS/SSA，其他编码明确记为 blocked；若不是完整 12 集，可调整期望集数和文件匹配。无 provider 配置，任何模型访问尝试会使验证失败。

未运行：真实影片 OCR、视觉模型、语义向量/查询模型、人工作品质量评测，以及 Windows/Linux 平台验收。PGS/DVD 等位图软字幕 OCR 仍未支持；现有 OCR 只读已烧录进视频画面的文字。

## 已知边界

- 采样式画面理解与字幕识别可能漏掉极短事件；当前不做 ASR 或位图软字幕轨 OCR；文本字幕轨已支持本地提取。跨镜头身份关联和人物裁剪可能出错，支持人工编辑、合并、删除后重新识别。
- 极低帧率视频中，如果单帧持续时间覆盖了整个后续分析窗口且其真实 PTS 在窗口之前，该窗口会报告失败，不编造窗口内时间戳；可扩大窗口后重试。
- 供应商中途断连或服务被强制终止时，无法确认远端计费。在途请求按最多三次保守计入请求预算，费用保持未知；核对供应商账单后调整预算继续。
- 新切分产生的新记录不会继承旧局部人物 ID 的身份映射；旧收藏仍保留并标为历史证据。
