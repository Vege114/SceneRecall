## 关键帧扫描提速与剩余五集验收（2026-10-23）

**采用结论。** 采用 C：批量登记／元数据复用加 PyAV 原生 PTS 解码。第 4、7 集合计处理时间由 **485.438 秒降至 280.641 秒，减少 42.188%**；两集分别减少 46.798% 和 36.897%，通过“合计至少 20%、任一集不得回退超过 5%”门槛。C 在六段短片中位数合计上比 B 再减少 26.737%，超过引入新解码依赖所需的 10%。结果距门槛充分，短片重复运行稳定，未追加整片反向重复。完整阶段、CPU、内存、输出体积和逐次测量保存在[脱敏 JSON](validation-keyframes-20261023.json)。这些是本机本批素材的结果，不是所有设备或编码格式的速度保证。

**方法与环境。** A 为提交 `c3c5b77dfed1b29de54c3e52da7eed2050926b04` 的完整后端归档，保留原默认 32 个 OpenCV 线程、像素管道／日志同步和逐图登记。B 使用每 128 张批量登记、关闭未使用的 `showinfo` checksum、复用本次 probe 元数据和 1 个 OpenCV 线程。C 在 B 上用 PyAV 直接提供像素及原生 PTS，保留原选帧规则、逐帧处理和 FFmpeg 高清精确取图。未使用跳帧、TransNet V2 或新的重复帧过滤阈值。环境为 Windows AMD64、Python 3.12.6、OpenCV 5.0.0、NumPy 2.5.3、PySceneDetect 0.7.1、PyAV 18.1.0、外部 FFmpeg 9.0.2；锁文件固定到实测的 PyAV 18.1.0。
