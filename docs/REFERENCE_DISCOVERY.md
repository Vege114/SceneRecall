# 参考图候选发现

作品设定库中的“参考图候选发现 · 无 VLM”将已人工确认的概念参考图与该作品已有影片帧特征比较，返回供人工核对的候选。此功能依赖[知识资料库](LIGHTRAG.md)和已有直接视觉索引；不要求 Bangumi 档案。

1. 为可见概念添加并确认参考图，在知识面板提交发现任务。
2. 在任务队列查看进度，完成后刷新候选。界面并排显示参考图、影片原帧、时间和相似度，并可播放原片段。
3. 查看原帧后填写核对依据，再确认出场。只有该操作才能创建确认绑定并进入知识召回。

任务复用现有影片向量，仅为缺失的参考特征编码；不重新扫描整片，也不调用生成式视觉模型。每个概念最多保留排序前 50 个候选。相似度不能证明身份、能力发动或事件成立，抽象概念仍不能直接确认出场。

候选保存参考 ID、原帧、记录、编码器签名和证据摘要。参考、影片、索引编码器或证据发生变化后，旧候选会标记失效；确认前再次校验版本，拒绝失效候选。任务运行中变化也不会发布旧候选。

API 位于 `/api/work-entity-scopes/{scope}/knowledge/`：`POST reference-discovery`、`GET reference-candidates`、`POST reference-candidates/{candidate_id}/confirm`（含 `reason`）。全部沿用本机会话认证及普通任务队列的取消/恢复控制。

`tests/test_reference_discovery.py` 和知识 HTTP/前端候选交互测试覆盖缓存复用、当前帧绑定、失效保护与人工确认门槛。[历史实验](LIGHTRAG_EXPERIMENT_20261028.md)只验证小样本复用与生命周期，不代表全片候选精度、确认率或人工审核效率；本次拆分未重跑真实库或模型。
